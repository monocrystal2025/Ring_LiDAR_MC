# 三项并列优势：统一参数鲁棒性图

主图为 `figures/three_benefits_w125.png`（另有矢量PDF和可编辑FIG）。三行依次是角宽降低、盲区相对降低、有效回波脉冲增加；三列依次是能量、反射率、大气消光。三项指标使用同一组参数配置、相同配对bootstrap方法、相同正收益方向和相同图形风格，不设置主次。

这是新程序实际计算的局部敏感度分析。主图为动态512、静态2048个目标，不是原来的每配置3000个样本。原N=3000宽范围数据用于补图，不能混淆样本量。

## 研究范围及取舍

E=150 μJ、rho=0.5、alpha=1.5e-5/m为基准，逐个作±20%扰动，五级水平。alpha/beta固定50 sr，其余系统参数保留原稿设置，ROE模式。剔除速度列是因为静态盲区定义与目标运动速度无关；选取三种都会影响回波的参数，对三项指标都有实际意义。

角宽要求为15秒检出比例60%，直接使用原始经验曲线的首次交点，不做平滑或单调包络。全部计划角宽均计算，按相邻网格插值；验证要求主图全部交点括区不大于5 mrad。若某配置未达标，程序保留NA并使完成核验失败，不会自动删除该配置。

盲区和脉冲使用共同角宽125 mrad；100和150 mrad作为补充工作点。有效脉冲是首次成功检测窗内期望信号光子数>0的脉冲，沿用论文定义，未乘展示系数。动态角宽指标用15秒事件，脉冲统计用完整进入至出界仿真。成功目标条件均值与无条件检测概率不是同一指标。

研究区间和125 mrad工作点参考了已有结果，属于明确披露的探索性工作区间选择，不是预注册范围或测得的硬件容差。宽范围补图保留原始全部20行配置（含重复基准）、NA及负收益。不能把局部主图推广成整个参数域内普遍优越，也不能把逐个扰动解释成任意联合扰动。

## 理论解释

固定几何下信号随能量和反射率增加；在本范围内增强大气消光及后向散射会降低绝对探测性能。代码逐目标核对这些方向，出现违例将阻止完成核验。相对收益是两种光束响应的比值，不需要单调随参数增强。两种光束在强回波下都接近几何限制时，角宽优势可能收敛。

脉冲数量还受到首次成功窗终止时刻、局部能量稀释和成功目标选择的共同影响；增强回波可以减少达到报告门限所需的脉冲。因此“脉冲越多即检测越好”不是本图的推理。它应与角宽和盲区结果及原稿回波簇分析共同解释。额外保存共同成功目标脉冲对照，避免把条件均值误作所有目标的因果比较。

## 产物

- `design.md`：计算前记录的研究设计与解释边界。
- `run_unified_robustness.m`：新仿真入口，独立随机种子，保存目标、配置、内核源码和成功光子窗。
- `analyze_unified_robustness.m`：三种收益和配对不确定性、共同成功目标对照、物理方向核验。
- `plot_unified_robustness.m`：一致的3×3主图、100/150 mrad补图、绝对响应图、完整原宽范围边界图。
- `write_unified_manuscript.m` / `manuscript.md`：实际数值驱动的中英文正文、图注、范围说明。
- `verify_unified_robustness.m` / `results/verification.json`：完整配置、无NA、网格分辨率、物理方向、补图反例保留及文件检查。
- `results/three_benefits.csv`：各配置三项绝对响应、相对收益、点态和同时区间。
- `results/analysis.mat`：分析快照及逐目标紧凑数组，含共同成功样本收益和样本数。
- `results/case_XX_width_XXX.mat`：真实仿真结果，支持重新统计和窗内脉冲计数复核。

主图画95%点态区间；CSV另给覆盖13配置×3项指标的近似95%同时区间，并列出角宽插值括区及bootstrap双光束可达比例。若有少量不可达重采样，角宽区间条件于可达重采样；比例低于97.5%时不报告有限区间，并阻止完成核验。置信区间衡量目标采样不确定性，不包括网格插值、模型误差、实际光子噪声和参数分布不确定性。
